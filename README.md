Funcionamiento:
1. Solicita subir una foto de tu heladera o alacena donde se visualice correctamente los productos que contiene para ser identificados por una IA.
2. Se debe presionar el boton "Analizar Heladera".
3. Este botón envía una solicitud a una IA que requiere de una API KEY, si no se posee una se debe crear una y guardarla para futuros usos de esta Mini App.
4. La IA analiza el contenido de dicha foto y devuelve recetas de comida para hacer utilizando solamente los productos que tienes en tu heladera/alacena.
5. Se da por sobreentendido que posees condimentos, agua, fuego para cocinar etc.
